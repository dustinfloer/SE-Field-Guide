Data Flow Mappings

SAP → Shopify Product / Catalog Sync
Product master data flows from SAP to Shopify. Includes pricing, descriptions, and availability.
Material → Product
Material Variants → Variants
Pricing Conditions → Price Lists
SAP → Shopify Inventory Sync
Real-time or scheduled ATP (Available-to-Promise) quantities sync to Shopify inventory levels.
ATP Quantity → Inventory Level
Plant → Location
Shopify → SAP Order Sync
Orders placed in Shopify are sent to SAP for fulfillment, invoicing, and financial posting.
Order → Sales Order
Line Items → Order Items
Shipping Address → Ship-To Partner
Bidirectional Company / Customer Sync
B2B companies and contacts sync between systems. SAP is typically master for existing customers.
Company ↔ Business Partner
Company Location ↔ Partner Address
Company Contact ↔ Contact Person
SAP → Shopify Fulfillment Updates
Shipment confirmations and tracking info flow back to Shopify to update order status.
Delivery → Fulfillment
Tracking Number → Tracking Info
SAP → Shopify B2B Pricing & Terms
Customer-specific pricing, payment terms, and credit limits from SAP configure Shopify B2B settings.
Condition Records → Price Lists
Payment Terms → Payment Terms
Credit Limit → Spending Limit

Key Integration Concepts

🔑 External IDs
Every synced object stores a reference ID from the other system. Shopify uses metafields; SAP uses custom fields. Essential for update operations and deduplication.
📡 Webhooks vs Polling
Shopify webhooks push changes instantly. SAP typically requires polling via OData/RFC APIs. Middleware normalizes these patterns into a unified event stream.
⚖️ System of Record
Determine which system "owns" each data type. Typically: SAP owns products, pricing, inventory. Shopify owns orders, cart data, customer preferences.
🔄 Idempotency
All operations must be safely repeatable. Use unique transaction IDs and upsert logic to handle retries without creating duplicates.
⏱️ Near Real-Time vs Batch
Orders typically sync in near real-time (seconds). Inventory may be near real-time or batched. Product catalog updates are usually scheduled batches.
🛡️ Error Handling
Failed syncs go to dead-letter queues. Middleware provides alerting, retry mechanisms, and manual intervention workflows for resolution.
